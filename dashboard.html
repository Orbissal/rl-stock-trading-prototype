Project Overview

An Intelligent Stock Trading Advisor using Reinforcement Learning, submitted as the CM3070 Final Year Project for the BSc Computer Science at the University of London.

The system employs a three-tier progressive architecture balancing theoretical rigour with practical implementation constraints.

Architecture

T1
Tabular Q-Learning
40-state discrete space (RSI × trend × position). Trains in under 2 minutes. Sharpe 0.79 on holdout.
T2
Deep Q-Network
11-dimensional continuous state. Experience replay + target network. Sharpe 1.61 in 2022 bear market.
T3
Web Interface (this)
Flask API + dashboard. Live inference on AAPL. Rule-based explainability output.

Key Findings

  • DQN outperforms buy-and-hold in bear markets (+43.59% vs −28.20% in 2022)
  • Neither agent consistently beats passive strategies across all regimes, consistent with Fischer (2018)
  • DQN achieves the smallest maximum drawdown in all three evaluated regimes
  • Overtrading in trending markets is the primary constraint on DQN performance

Technology Stack

  • Python 3.10+, TensorFlow 2.x (Keras), NumPy, pandas
  • yfinance for live market data (Yahoo Finance)
  • Flask + Flask-CORS for the REST API
  • Chart.js for performance visualisations
